# Examples

- [api-security-notes/](api-security-notes/): a static, no-build notes site produced while
  demoing the dashboard. It has search, category filters, an accessible card grid and an OWASP API
  Top 10 (2023) coverage bar. Open `index.html` in a browser. Notes titled `PLACEHOLDER` /
  `STARTER` are drafts generated from the official OWASP pages, not curated team notes.
